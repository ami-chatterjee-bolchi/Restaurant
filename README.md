# 🍽️ Crispy Confessions – Restaurant Web Portal

A visually rich, responsive, and interactive restaurant website. **Crispy Confessions** is designed to provide a seamless user experience, from exploring a diverse multi-cuisine menu to booking a table and calculating order costs in real-time.

---

## ✨ Features

* **Dynamic Hero Section:** A bold, high-impact landing area with a parallax-style focus.
* **Integrated Order System:** Includes a real-time **JavaScript cost calculator** that updates totals instantly as quantities are entered.
* **Table Booking Engine:** A dedicated interface for reservation management (Seating for 4, 6, and 8-seaters).
* **Chef’s Gallery & Achievements:** Showcasing the culinary experts and industry awards (Best Taste 2023, Hygiene Star 2024).
* **Branch Locator:** Cards detailing premium outlets across Kolkata (Park Street, Jadavpur, New Town).
* **Video Branding:** Integrated video backgrounds for an immersive brand storytelling experience.

---

## 🛠️ Tech Stack

* **HTML5:** Structured semantic markup for SEO and accessibility.
* **CSS3:** Modular architecture (split into 9+ specific stylesheets for maintainability).
* **Bootstrap 5:** Utilized for a responsive grid system and award-gallery cards.
* **JavaScript:** Logic implementation for real-time order calculations.
* **Google Fonts & FontAwesome:** Custom typography (Cookie, Fredericka the Great, Monoton) and iconography.

---

## 📂 Project Structure

To maintain clean code, the CSS is modularized:
```text
├── index.html          # Main structure and logic
├── rest.css            # Base styles & Hero section
├── menu.css            # Menu grid and box layouts
├── order.css           # Order forms and JavaScript integration
├── table.css           # Reservation form styling
├── chef.css            # Expert chefs gallery
├── achievement.css     # Award cards and branch layouts
└── (Additional modules: about, video, contact, etc.)
```

## 🚀 Installation & Usage
1. **Clone the repository:**
   ```bash
    git clone [https://github.com/your-username/crispy-confessions.git](https://github.com/your-username/crispy-confessions.git)
    ```
2. **Assets:** Ensure all local images (about (1).png, logo final.png, etc.) and the video.mp4 are in the root directory.

3. **Run:**
    Open index.html in any modern web browser.
